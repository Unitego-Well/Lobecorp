## 1. 目标与不可改变的边界

1. 重建可制作、预览、组合、运行和诊断的模型特效能力；以真实激光、法阵、光球、星束及 counterattack 资产为交付样本。
2. 兼容用户当前文件，保留资源 ID、对象/部件/动画/形参/轨道/片段 UUID、层级、参数意义和已有播放语义。
3. 先解决首次/间歇后播放与连续拖动的长阻塞，再扩展完整模型工具；不以功能数量、平均 FPS 或线程利用率代替交互验收。
4. 保留原生 Photon 入口与 /lobecorp photon_editor 的安装隔离；命令、MCP、界面共用同一编辑与参数事务。
5. 实体动画、实体模型 LOD、技能权威时序、伤害、阵营、冷却、命中框及已有网络职责不变；需要实体位置/姿态时使用只读输入。
6. 保留当前画质为默认基线。减少粒子、降低几何/动画精度、降低分辨率、关闭 Bloom 或改变透明语义属于质量取舍，必须单列并确认。
7. 不默认新增外部 SDK、DCC 依赖、原始 OpenGL 出口或全新文件后缀。软件作为设计参考；实际实现优先组合锁定依赖的公开能力。

## 4. 模型用途、来源和动画方式是三个不同维度

### 4.1 用途

| 用途         | 生命周期                 | 典型内容                           | 运行要求                                             |
|--------------|--------------------------|------------------------------------|------------------------------------------------------|
| 独立模型对象 | 一个可寻址对象及若干部件 | 激光外壳、法阵、能量球壳、武器投影 | 时间可直接求值；无需为了显示一件物体运行粒子发射过程 |
| 模型粒子     | 发射器管理多个短期实例   | 碎片、飞剑、能量花瓣               | 共享拓扑/材质；每实例变换、寿命、颜色、动画相位独立  |
| 模型采样器   | 提供输入，不隐含可见物体 | 表面发射、骨骼/部件位置、轮廓轨迹  | 标明静态/变形后采样；只读，独立预算与缓存            |

旧模型发射器通过兼容映射恢复旧生命周期，不能默认改成独立模型而改变发射数量、寿命或层级。

### 4.2 来源

文件资产、程序化配方、运行端提供的动态网格都可成为来源。来源与用途正交：一个程序化环既可单独显示，也可发射多个；模型表面可只用于发射。外部动态来源必须声明拓扑身份、revision、缓冲有效期、所有权及释放规则。

### 4.3 动画执行能力

静态/TRS、部件曲线、骨骼、Morph、VAT、程序化变形分开声明。每个来源报告支持的动画、材质、法线/切线、采样、直接 seek
和实例化能力。无法支持的组合在编辑/导出前报告；不静默丢失。

## 5. 功能清单与分期原则

分期只决定实现顺序，不减少已保存文件的兼容要求；某个旧文件使用尚未恢复的能力时，该文件的兼容状态仍为未通过。实际资源已使用的 Morph、命名/子动画、发射调度、激活及材质行为属于 G1 前置功能，不能作为 R4 新特性延后；未被本批资源使用的新增能力不抵扣兼容进度。

| 功能组     | 必须规划的内容                                                | 初步阶段               | 可观察验收                                                      |
|------------|---------------------------------------------------------------|------------------------|-----------------------------------------------------------------|
| 模型基础   | 部件层级、面角 UV/法线、材质槽、枢轴、参考尺寸、坐标轴        | R1                     | counterattack 渲染/选取/保存往返一致                            |
| 特效几何   | 环、圆柱/圆锥、球壳、旋转截面、丝带/沿路径扫掠                | R2                     | 改参数只失效相关准备结果，端点/接缝正确                         |
| 伸长/锚点  | 整体缩放、局部区间伸长、START/END 部件、宽度/长度独立         | R1–R2                  | 起点固定、终端移动、纹理密度可控                                |

| 动画       | TRS、部件、骨骼权重、Morph、片段、插值、循环/反向/暂停        | R2–R3；已有 Morph 优先 | light_ball/queen_star_beam 的 Morph 与实例时钟通过后才能放行 G1 |
| 命名播放   | UUID/名称、句柄、默认/触发、参数、优先级、混合、HOLD/RELEASE  | R2–R3                  | 同定义不同播放不串状态，停一层不误停其他层                      |
| 输入与绑定 | 标量/向量/颜色/整数/布尔、默认/范围/单位、固定/实时绑定       | R1–R2                  | 字段来源/最终写入者可见，失效目标可定位                         |
| 子内容     | 模板/资源来源、形状/继承/跟随、出生/事件调度、受控/独立子动画 | R2–R3                  | laser_spell/star_beam_spell 的子播放、停止与清理属于 G1 必测    |

| 扩展专项   | GPU Morph/蒙皮、更多变形器、复杂节点图、GUI 独立呈现原型      | R4；最新授权可提前开展 | 单独记录实现及收益，不抵扣 G1，质量取舍仍须单独确认             |

复杂拓扑建模、权重绘制和大型解算可由外部软件制作输入；现有工程已使用的游戏内编辑能力仍需恢复，不以“交给外部软件”取消既有契约。

以下为逻辑职责，不是本轮创建 Java 类或包的授权。

    B --> C[可编辑文档与稳定身份]

    D --> E[不可变运行定义及共享资源]
    E --> F[实例时钟 参数 播放句柄]
    F --> G[隔离求值与模拟]

    J --> D

## 7. 模型数据与几何正确性

- 编辑顶点身份与 GPU 顶点索引分开。面角 UV、硬边法线、切线、材质边界可以拆分渲染顶点，原顶点/部件 UUID 不因此改变。
- 预先准备三角形、面角映射、部件索引、材质分组、拾取结构和依赖。改颜色/透明度不重做三角化；改 UV 不重解析骨骼。
- 骨骼、权重、Morph 和拓扑建立可验证映射。拓扑变化时明确重建/拒绝相关变形数据，不能继续使用旧下标。
- 定义模型局部、部件局部、骨骼、发射器和世界空间；单位、前向轴、轴向符号、矩阵顺序均可检查。
- 非均匀缩放使用正确法线变换；镜像处理绕序与切线手性；零缩放、退化面、非有限值有明确策略。
- Morph 应分别记录位置及可选法线/切线数据。只有位置增量时，选择并说明重算法线方案，不能宣称完整平滑法线插值。
- glTF 输入遵守 Morph 在 skin/node 变换之前应用的规则；自建旧资产按原规则解读。局部伸长插入哪一空间、怎样影响法线必须显式登记，禁止统一新顺序改变旧文件结果。
- 动态几何保持拓扑对象稳定，只发布几何 revision；拓扑改变另发 topology revision。缓冲借用期限跨越原生延迟绘制，绘制尚未消费前不得回收到池。

## 8. 程序化几何与有限变形栈

优先提供特效配方：环/圆盘、管/圆锥、球/半球壳、旋转截面、弧面、沿路径扫掠、条带。参数含轴、长度/半径、截面、角度范围、细分、端盖、UV
密度及种子。

每个操作声明是否改变拓扑、影响哪些属性域、输入空间、边界扩展与可直接求值性。固定细分的伸长/弯曲/扭转可仅更新几何；改变细分、环切、挤出需重新准备拓扑。

变形栈支持顺序、启用/旁路、部件遮罩、参数关键帧和自身耗时。普通面板暴露常用参数，复杂配方内部可折叠；首版不引入无限通用脚本或任意代码执行。

激光必须区别：

- 整体拉伸：全部轴向坐标按参考长度缩放；
- 局部伸长：固定前段、区间变形、后段平移；
- 端点/路径：由 start/end 或路径采样确定方向与长度；
- UV 随形拉伸与保持世界密度两种显式模式。

局部伸长、骨骼和 Morph 组合的正确性优先于合批；不能为了共享几何把不同变形实例错误画成同一个姿态。

## 9. 动画、时间与播放语义

保留当前文件 tick 单位及精度；内部若用秒或高精度采样时间，在适配边界明确换算，不改变已保存数值。时间、时长、速率、相位和模拟步长分别建模。

时钟至少区分：世界权威起始时刻、特效实例时钟、命名播放时钟、子播放时钟、编辑预览时钟。暂停、变速、循环、重启和 seek
对哪些时钟生效须在界面显示。原生全局 pinClock 仅为测试入口，不能作为实例时钟方案。

命名动画保留：

- 名称与 UUID 查询、独立句柄、形参及固定/实时输入；
- 优先级与启动顺序、覆盖/相加/相乘；
- HOLD/RELEASE、循环边界、运行中改变时长；
- 子动画受控/独立、后生成对象接入、替换句柄与清理。

求值基于确定的基础姿态，活动贡献先收集再按规则混合和应用。释放贡献时恢复剩余贡献/默认值，避免把上一帧结果继续叠乘。旋转、颜色、整数、布尔和非均匀缩放使用各自明确的混合规则。

动画后端按能力选择：
| 后端 | 适用 | 成本/限制 |
|---|---|---|
| 直接 TRS/部件曲线 | 法阵展开、模型位移/旋转/缩放 | 索引与曲线准备后按时间采样 |
| CPU 骨骼/Morph | 少量强交互、任意实时权重 | 纯输入快照；姿态/法线/上传分别计量 |
| 共享姿态 | 同模型/片段/时间/参数的多个使用者 | 仅相同语义共享，不用全局时钟强迫同步 |
| VAT | 大量预制动画、独立相位 | 帧表内存/烘焙/采样/插值及法线切线能力单列 |
| GPU 蒙皮/Morph 专项 | 量测证明 CPU/上传成为瓶颈后 | 原生兼容、ShaderGraph、调试与硬件后端先做原型 |

## 10. 参数、绑定与属性写入所有权

参数定义记录稳定 ID、名称、类型、单位、默认值、范围、作用域及可动画性。保留标量、向量、整数、布尔、颜色和已有表达式/曲线精度，不降成一套字符串取值。

绑定在准备阶段解析目标 UUID 和属性路径，形成类型化索引。运行时使用索引/槽位；对象删除、来源替换或重置代次改变后使绑定失效，诊断指出失效原因。

区分资产参数、特效实例参数、命名播放形参、对象参数、材质参数、出生参数与存活期参数。出生属性只影响后续粒子，不能把修改当前网格的行为冒充出生设置。

属性来源面板展示默认、外部输入、动画贡献、临时预览和最终结果。原生 Timeline 与 Java 对同一 RuntimeValue
的写入目前存在覆盖次序，适配层必须确定一个最终写入责任方，不能依赖偶然的“最后写入”。

表达式先解析/检查依赖和循环，再缓存可执行表示；每帧不重复解析字符串，不开放任意反射或脚本访问活世界。

## 11. 组合、事件与子特效

连续属性、生命周期状态和一次性事件分开。事件有来源实例/播放代次、事件 ID、时间、参数快照和处理策略；重复求值同一时间不重复派发。

正向跳跃派发经过区间内的合法事件；回退/拖动默认不向玩法或音频派发，循环、重启和录制按显式策略处理。停止发射、停止某动画、柔和结束、立即销毁和等待余粒子结束分别提供语义。

子特效/子动画设依赖循环检测、最大深度、活实例数、每帧事件/生成预算及取消规则。预算拒绝有可见原因，不默默丢内容。父停止时受控孩子联动、独立孩子按原约定继续；世界卸载/项目关闭全部清理。

模板输入、继承变换/颜色/参数、跟随与出生快照分别配置。已有形状、发射调度和子播放契约通过适配保留，不用统一重置替代。

## 12. 增量准备与资源就绪

准备流程：读取 → 原始校验 → 文件适配 → 拓扑/动画/绑定准备 → CPU_READY → 排队 GPU 准备 → READY。中间可取消，失败保存原因和来源字段；RETIRED
资源等待最后消费者释放。

共享键包含资产内容指纹、资源代次、解析/准备版本和会影响输出的设置；动画表再含片段、采样范围/帧数、必要姿态规则。实例颜色、位置、临时状态不进入不可变网格键。

依赖图记录模型、外部动画、材质、贴图、曲线、子模板和包资源。变更只失效依赖子图；组合动画依赖任一来源变化都失效。发布新资源时旧帧持有旧版本直到消费结束。

首发准备单独统计解析、复制、拓扑、动画/VAT、Shader/Pass、GPU 缓冲、首次绘制。加载字节、模拟预热、材质编译和 GPU
准备是不同工作，不用一个“预热完成”标签混合。

游戏技能权威时序不等待视觉任务。视觉若延迟就绪，按权威起点补偿时间并记录丢失的可见区间；不能延后伤害或重播音效伪装实时。需要提前准备的资源由明确生命周期请求，有界驻留，失败/失效可追踪。

## 13. 渲染与可扩展性

复用原生 Photon 材质、实例化、层、深度、混合、Bloom、后处理与 Iris 合成路径。模型输出适配器提交已完成的数据，不在绘制回调解析工程或同步烘焙大量动画。

合批按真实兼容条件：拓扑/几何来源、材质/Shader 变体、贴图/采样器、图层、深度/混合/剔除状态、布局及透明排序约束。不为每个实例复制相同材质；参数覆盖优先可合批的实例数据通道。

不能合批原因可定位到状态差异；不强行合并具有不同透明顺序的模型。多材质、多透明层、屏幕覆盖、噪声采样和大后处理均计入预算。

动态网格/CPU 姿态/VAT 的原生调用链必须先实测缓冲重建、上传及资源复用。若现有接入点不能维持稳定拓扑和独立时钟，先做最小适配原型/提出上游改进；不把“复用原生”当作性能已合格。

对象边界随实际变形保守更新，记录固定/动态/准备期包络策略。顶点位移材质必须声明边界扩展；越界或保守扩大要可诊断，避免错误剔除。特效
LOD 与现有实体 LOD 分离，任何画质改变另行确认。

## 14. 多线程职责与发布规则

| 工作                              | 默认线程/所有权                 | 可并行条件                            | 回交/限制                         |
|-----------------------------------|---------------------------------|---------------------------------------|-----------------------------------|
| 用户输入、命令、MCP、编辑历史     | 客户端/UI 所属线程              | 不并行修改同一文档                    | 一次事务产生 revision             |
| 原始字节读取、纯格式解析          | 有界准备执行器                  | 资源管理器/来源读法经审计，先固定版本 | 只回不可变数据/诊断               |
| 三角化、曲线/绑定编译、VAT CPU 表 | 准备工作线程                    | 输入不可变，无 UI/世界/GPU 调用       | 可取消、有总内存预算              |
| 模型姿态、纯几何变形              | 求值工作线程或同线程快速路径    | 独占工作区、稳定输入、任务粒度足够    | 完整快照原子发布                  |
| 粒子/碰撞/音频/原生对象变更       | 遵守原生所属线程                | 仅审计过的原生并行区间                | 不将整个 FXRuntime 随意搬入线程池 |
| GPU 创建、上传、Pass、绘制/释放   | 原生渲染线程/受支持调度         | 不假定共享上下文安全                  | 帧预算、延迟消费、栅栏/生命周期   |
| 分析、排序、导出                  | 已冻结的诊断数据 + 有界后台任务 | 不读活 UI/世界                        | 最新版本结果才应用                |
| GUI 绘制与主窗口呈现              | 当前原生线程                    | 独立呈现仅进入专项原型                | 见第 15 节                        |

不按模型/顶点无条件创建任务，不同时叠加外层工作池与原生 parallelStream 导致过度订阅。短任务同线程执行；并行阈值通过当前硬件/内容量测，而非复制原生阈值。

任务携带 project/session ID、文档 revision、资源代次、request ID、目标时间和取消标记。结果应用前全部校验；关闭、切工程、撤销/重做、资源重载和世界卸载会使旧结果失效。

UI/渲染线程不调用等待整项计算完成的 join/get；队列同时受任务数、估计字节与在途输出限制。取消协作完成，已分配缓冲可靠回收；已提交
GPU 工作不能只取消 CPU future 后提前释放。

## 15. GUI 独立线程渲染研究路线

保留为正式需求，但拆成可验收的两级：

1. 基线：重计算离开 GUI 热路径，主线程消费上一份完整预览；输入、命中测试、状态文本和取消操作保持可执行。
2. 专项原型：独立 UI 状态/绘制命令、资源与上下文、完成纹理交接、输入命中版本、主窗口合成/present、窗口缩放/DPI、关闭和异常清理。

GLFW 同一 OpenGL 上下文不能同时属于两个线程，事件处理也受主线程约束。共享纹理或离屏生成不保证主窗口在原渲染线程阻塞时仍呈现新内容。若原型只能后台生成画面但主窗口未刷新，不计“GUI
已独立响应”。

原型验收同时人为阻塞模拟、资源准备和原生绘制路径，分别测输入接收、命中处理、UI
更新与最终呈现；只把后台统计线程启动成功当作结果不合格。是否采用独立上下文/更大宿主改造，待成本和兼容原型后确认。

## 16. 时间轴求值、seek 与检查点

对象先声明：

- 可直接按时间求值：纯曲线、TRS、部分部件/Morph/材质；
- 需历史模拟：粒子出生/死亡、碰撞、反馈、拖尾与有状态子发射；
- 需要外部输入历史：随实体/世界变化的绑定，不能拿当前状态伪造过去。

交互请求状态为 requested → queued → computing → ready → applied，另有
superseded/cancelled/failed。最多保留最新目标和必要在途任务，不保存所有鼠标位置形成无界历史。

同目标且内容/输入/资源版本未变可复用；同一时间发生编辑后必须重新求值。分离目标时间与已完成时间；未完成时继续显示上一张完整预览并标识计算中，不能显示目标数字却仍停在被截断的旧状态。

检查点包含实际需要的粒子/拖尾/发射余量、随机状态、对象层级/生命周期、子实例/播放/事件去重及输入历史引用。原生定义序列化或普通
copy 不自动等价于完整运行检查点。不能完整捕获的模块标记不支持恢复，回退到有界重放。

检查点与完整 Sim Cache 分开：前者降低重放距离，后者保存大量时间状态。采用总字节预算、选择性模块、最近/稀疏点和失效代次，不默认缓存全部帧。插值只处理身份连续且有定义的属性，出生/死亡边界不能随意插。

阶段性先让必须留在原线程的原生重放按预算切片；只有审计过的纯求值迁到 worker。取消仅在一致边界中断。单帧切片建议先研究 1–2
ms 目标，数值须根据完整帧成本校准，不是已达性能。

## 17. 编辑器、事务与自动化

工作区按“模型/UV/动画/材质/诊断”切换，保留原生停靠、标题、资源目录、历史、快捷键与游戏内嵌入。视口使用透视；模型、对象、部件、骨骼和面选择有清楚的活动目标。

几何编辑命令记录选中身份、before/after patch、引用变化、revision 与合法性；一次拖动按事务合并，取消恢复原状态。拓扑编辑同步校验
UV、法线、权重、Morph 和片段目标；失败不污染 dirty 或历史。

来源发射器应用操作校验项目/运行代次、UUID 与对象身份，防止把预览副本写回已删除/被替换的对象。预览参数不进入保存；应用必须为显式事务。

资源预览器可独立查看静态/动画模型、部件/材质、UV、法线/切线、边界和内存；效果视口用于组合验收。显示正在看的定义、实例、时间与编译版本。

MCP 与 GUI 采用同一参数/编辑/seek 队列。保留现有操作语义；若将当前同步 seek
改为异步，需保留旧客户端“返回即完成”的兼容入口或设计明确的协议能力协商、request/status/await，不静默改变返回语义。

## 18. 性能检测设计

身份树：会话 → 特效资源 → 运行实例/代次 → 对象/子实例 → 模型部件/材质或动画播放/轨道 → 阶段 → 线程/时刻。资源 UUID
与播放身份分离；同名、同 UUID 复用、重置和子播放上下文不能合并。

| 类别   | 最低检测内容                                                                     |
|--------|----------------------------------------------------------------------------------|
| 输入链 | 指挥家输入/预览/发送/服务端施放/客户端接收/创建/首个可见结果；关联 ID 与实际时刻 |
| 准备   | I/O、原始检查、解析、复制、三角化、绑定/曲线、动画/VAT、Shader/Pass/GPU 创建     |
| 运行   | tick、动画/表达式/混合、骨骼/Morph、法线/切线、边界、子事件、清理                |
| 渲染   | 提取、排序、几何生成、基础缓冲重建、上传字节、批次/提交、GPU Pass/Bloom          |
| 异步   | 排队、执行、取消检查、被替代、丢弃、发布、应用、锁/汇合等待、关键路径            |
| 内存   | 分配/保留/峰值、缓存字节/命中/驱逐、工作区/借出缓冲、CPU/GPU 表及释放            |
| 工具   | 采集、身份映射、快照、聚合、过滤、面板刷新与导出成本、容量/丢样/截断             |

CPU 展示墙钟 inclusive/self、调用次数/单次最大值，支持时另列线程 CPU。并行阶段父子墙钟不直接相加，关键路径与总 CPU
分开。JFR/Spark 等用于独立交叉检查，未来运行须按授权执行。

GPU 使用异步查询，避免立即读回等待；共享 draw/pass 只报告共享成本和参与者，不按对象数虚构每模型精确 GPU 时间。CPU 提交不当
GPU 时间，未测为 unavailable，不是 0。

面板提供帧图、长帧排序、对象/模型/动画树、时间范围、线程/来源筛选、编辑器定位、首发/稳定分类和原始导出。点击模型可反查批次与分组原因，点击动画可反查目标与执行播放。

采集模式：关闭、概览、选中子树详细、短时 GPU。所有身份/事件/聚合/等待/导出有预算；容量耗尽冻结证据并显示原因，不能继续显示完整报告。预算优先保留根阶段和关键阻塞，避免细粒度节点挤掉关键卡顿。

建议概览工具额外帧成本中位数不超过 0.2 ms，详细模式报告绝对开销与相对开销；该建议需基线校准。冻结导出/后台分析使用稳定快照，刷新不可复制全会话所有事件。

保存/另存/导出使用临时目标、校验、原子替换及失败回退。兼容门禁按文件所需能力判定：该文件所有已用类型/字段/依赖往返通过后才解除对应保护；不在新加载器刚出现时全局关闭保护。
