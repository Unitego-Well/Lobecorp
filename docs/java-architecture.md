## 包职责

| 包 | 责任 | 不应承担 |
| --- | --- | --- |
| `api` | 跨域接口、扩展契约 | 实体运行状态 |
| `entity` | 实体、AI、导航和实体客户端表现 | 注册入口、网络协议 |
| `entity_skill` | 技能定义、请求、运行实例、效果和技能适配 | HUD 布局、世界目录 |
| `conductor` | 指挥家目录、控制、移动、队形和远程命令 | 客户端绘制细节 |
| `hitbox` | 命中框几何、生命周期和效果应用 | 技能状态机 |
| `animation` | 动画层、状态和过渡 | AI 决策、伤害逻辑 |
| `registry` | NeoForge 注册对象和注册生命周期 | 运行时业务逻辑 |
| `events` | 唯一事件订阅入口和有序分发 | 持久化状态机 |
| `network` | Payload 定义、编解码和协议分发 | 绕过服务端校验修改实体 |
| `client` | HUD、镜头、输入、会话和缓存 | 服务端权威数据 |
| `mixin` | 原版桥接和最小拦截 | 复制业务状态机 |
| `util` | 无状态可复用的 `*Util` 方法 | 持有实体、世界或渲染对象 |

## 调用方向

业务调用优先经过所属域的公开接口或工具入口：

- 指挥控制通过能力接口和 `ConductorUtil`。
- 指挥附件通过 `ConductorAttachmentUtil`。
- 实体技能通过 `EntitySkillAccess` 能力；技能状态机由 `EntitySkillUtil` 内部推进。
- 技能运行数据不写入世界存档；世界目录只保存世界级摘要和待交付记录。
- Mixin 只调用能力、事件分发或工具入口，不长期缓存能力对象。
- 客户端只消费同步快照，不反向修改服务端附件。

## Conductor 子包

- `conductor/ability`：能力契约、目标预览、能力状态和实体技能适配。
- `conductor/data`：世界目录、单位持久化字段和客户端目录快照。
- `conductor/control`：EntityCapability、单位控制、移动、攻击、声波和清理工作。
- `conductor/world`：区块票据与世界级运行状态；`conductor/lifecycle`：目录和战斗生命周期处理。
- `conductor/util`：附件与能力的 `*Util` 统一入口；`network`：指挥命令与目录快照 Payload。

## 注释规则

- 类注释用一句话说明职责和边界。
- 公共方法注释说明输入、输出和副作用；没有额外约束的方法不写重复实现细节。
- 只解释业务原因、生命周期约束或版本敏感点，不记录开发过程和历史替代方案。
- 业务常量、资源 ID、规则参数放在集中管理的位置；注释说明用途，不重复数值含义。
- 注释和类名保持同步；移动或重命名后同时更新引用和文档。
