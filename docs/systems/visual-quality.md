# 动态视觉精细度与自动 LOD

> 2026-10-23 文档边界：实体动画与实体模型 LOD 的共同基础说明保留，本轮没有重新验收或修改其行为；Photon 旧模型 LOD／性能比较属于历史，当前特效范围见 [Photon 工作区](photon-workspace.md)。

> 2026-10-19 当前状态：实体动画与实体模型 LOD 及其配置保留；仅拆除 Photon 特效密度、自建模型 LOD、遮挡/排序/缓冲等专用优化。 实际检查与备份见[移除实施记录](photon-removal-result.md)。下文涉及已移除实现的说明仅保留为历史参考。

核对日期：2026-10-19。本功能只改变客户端视觉工作量，不改变技能、伤害、碰撞、移动或服务端动画时间。原始模型、纹理和着色器保持；自动烘焙结果存于内存缓存，不改写源模型。

## 设置入口

- 模组列表 → Lobecorp → 配置 → `lobecorp-visual-quality.toml`。
- 游戏内扩展编辑器 → 设置 → Lobecorp → 动态视觉精细度。
- 开发客户端文件：`run/client/config/lobecorp-visual-quality.toml`。

编辑器中的 31 个设置项、五个分组及说明均提供中英文翻译；提示按说明、默认值、范围分别传入 Component，不将 NeoForge 带换行的整段注释直接传给单个提示。扩展编辑器左侧的外观、行为、快捷键也按语言显示，设置树的逻辑路径与注册 ID 不变。

两个界面使用同一份 NeoForge 客户端配置。编辑器界面使用草稿，应用时保存，取消不修改运行值；豁免名单以英文内部名称、控制器名称或完整实体注册 ID 精确匹配。设置直接影响后续采样和出生，不补发此前省略的粒子。

| 分类 | 默认规则 | 可设置项 |
|---|---|---|
| 特效密度 | 50～96 格逐渐降低，最低 25% | 总开关、近/远距离、最低密度、可见负载自适应开关、负载预算、发射器豁免名单 |
| 负载响应 | 预算 12000；降低响应 0.15 秒，恢复 2 秒 | 两种响应时间，按真实经过时间平滑，避免随帧率改变响应速度 |
| 实体动画 | 50 格外 30 FPS，80 格外 12 FPS | 总开关、距离、两个采样帧率、实体 ID 与控制器名称豁免名单 |
| 特效网格 | 50/100 格两档，聚类网格 20/8 | 模型总开关、距离、网格精度、至少 128 三角形才简化、模型名称豁免 |
| 平面特效 | 全局允许，具体发射器默认不允许 | 全局允许开关、逐发射器“允许远处平面简化” |
| 实体几何 | 至少 64 个立方体；两档细节尺寸 0.5/2 模型单位 | 复杂度门槛、两档细节尺寸、实体 ID 豁免；16 模型单位等于 1 格 |
| 缓存与迟滞 | 每种烘焙缓存 256 项/32 MiB，每种每帧最多烘焙 2 个模型；恢复迟滞 4 格 | 条目数、预算、每帧烘焙数、距离迟滞 |

默认三个近距离阈值均为 50 格，当前开发客户端配置也同步为 50。阈值以内立即恢复完整精度，距离迟滞不跨入此范围；特效负载自适应也只作用于阈值以外。已有安装的旧 TOML 不会因 Java 默认值变化自动重置，仍可在上述设置中调整。

远处控制器保留现有降频采样和缓存回放策略。女皇代码动作在近距使用连续显示时钟，每个渲染帧计算；远距按相同 30/12 FPS 缓存姿态和过渡权重，并沿用 action/实体豁免；女皇上半身不再被整份服务端 tick 姿态替换，动作和瞄准俯仰在客户端合成。该修复不增加远处控制器采样频率，见[女皇技能特效](queen-beam-skill-effects.md)。

可见负载按本帧可见粒子和原网格三角形估计，不是 GPU 毫秒或硬性帧率保证。编辑器 DummyWorld 预览保持完整精度，普通世界才使用特效降级。

## 逐对象与实例豁免

发射器“始终保持完整精度”同时豁免出生密度与模型网格降级。发射器发射器的子实例保留原生生命周期，继承父源的豁免；在零出生 tick 保留小数余量，避免低频源永久停发。首次有效出生至少保留一份，后续按余量分散出生，不清空已有粒子。

代码创建的桥接效果可对一次完整播放设置：

使用 `effect.setQualityExempt(true)` 豁免，使用 `effect.setQualityExempt(false)` 恢复自动精细度。

实例开关不覆盖工程原有的逐发射器豁免。实体模型可用 `LcModelLodUtil.setExempt(entity, true)` 豁免单个实例；配置名单豁免整个实体类型。

## 自动模型烘焙

PhotonModelLodUtil（历史路径：`../../src/main/java/org/unitego/lobecorp/util/photon/model/PhotonModelLodUtil.java`；当前 dev 未保留）按材质组独立进行空间、UV 与法线方向聚类，去掉退化和重复三角形。拓扑从资产参考姿态烘焙，再映射到当前姿态；不能用出生时的零长度、零缩放姿态永久确定拓扑。输出姿态独占，缓存不借用引擎顶点缓冲。

简化没有减少实际 CPU 四边面提交量时回退原网格；少量几何和图集 UV 网格也回退。蒙皮与 Morph 特效网格保持完整，避免错误焊接不同骨骼或形状键的顶点。远处平面化压缩局部最短轴，保留材质与 UV，属于几何近似；有明显体积轮廓的效果应保持该逐对象选项关闭。

[实体模型 LOD](../../src/main/java/org/unitego/lobecorp/util/animation/LcModelLodUtil.java)自动准备两档可省略的小细节列表。骨架、骨骼名、定位器和主要几何保留；有定位器的部件、全部由小体素构成且无法可靠区分主体的部件保持完整。未达到复杂度门槛的模型不省略几何。源码目前只给女皇和清道夫渲染器接入，其他实体没有票据时沿原渲染路径。

烘焙分帧限量，预算不足暂绘制原模型。几何缓存有条目和字节上限，资源重载、退出和世界卸载清理；活动实例自己的输出姿态由实例拥有，不计作全局缓存。

## 动画只降低姿态采样

[控制器工具](../../src/main/java/org/unitego/lobecorp/util/animation/LcAnimationControllerUtil.java)新增 `withDistanceLod(controller)`，用法与首次姿态工具一致。当前只给女皇与清道夫的 5 个控制器显式接入，其他 GeckoLib 实体默认不变；还核对注册命名空间和真实客户端世界。

原生控制器检查、时间、声音、粒子和指令关键帧继续推进。缓存只持有本层姿态贡献，首次显示、动画/骨骼身份变化、触发版本变化、时间回退和循环边界重新采样，不把另一层的绝对姿态写回。既有混合层新建采样状态时传递降级请求；低帧采样不改变首次姿态立即生效规则、层权重或服务端技能时序。

## 统一修复渲染

扩展编辑器将排序与遮挡合并为“修复渲染”，保留层、Order 与遮挡 Alpha 阈值，移除两项独立开关。原生渲染器默认仍关闭。独立模型、桥接播放、子实例及模型材质副本都接入；副本每次转发有效状态与阈值，避免只有外层配置开启、实际材质仍关闭。

2026-10-18 在游戏内为 11 份现有 FX 工程及对应定义开启，两份参考、三法阵、蓄力资源、lasel、laser、laser_spell 与 queen_star_beam 均包含。5 个已有依赖包内的 11 份本模组定义也已更新，88 个其他条目内容逐项保持不变；模板的模型、着色器、颜色、对象、参数及动画未改。

不透明遮挡继续按已有管线支持范围运行：普通 HDR/Pixel/Sprite 材质支持，ShaderGraph、未知自定义着色器保持原管线。视深按同 Order 的绘制作业排序，不能保证相交透明面的逐像素正确性，详见[粒子与渲染](particle-rendering.md#排序深度与混合)。
