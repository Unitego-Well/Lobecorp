# 演出公共控制 API

适用范围为主分支游戏演出与指挥视角。女皇子分支负责的实体动画、激光与 Photon 时间线实现未迁移；编辑器时间轴、基准夹具和操作系统窗口控制不属于游戏演出调度。

| 入口 | 契约与接入 |
|---|---|
| PlayerInteractionControl.acquire/release | 按来源持有键盘、鼠标、移动、转向限制；限制取并集，Esc交给最高优先级的键盘接管者。清道夫使用完整限制，指挥家使用移动限制。按键释放与重复事件被消费，防止跳过后长按Esc打开暂停。 |
| CameraControl.register/unregister | 有效来源按优先级独占机位、角度、偏移和FOV，同级后注册优先。清道夫200、指挥家100；移除后恢复下一个有效来源或原版。 |
| ICameraController | independent提供独立机位，position提供相对位置，angles/fov提供角度与视野；不写用户选项。角度事件仍允许原有浪潮和落地震动叠加。 |
| PresentationTimeline | 调用方提供游戏时钟，start/time/seek/active/cancel统一播放位置与一次性收尾；清道夫正常播放、字幕补播和Esc切换均使用该入口。 |
| TimelineUtil | 无客户端依赖的阶段与关键帧采样，供服务端朝向与客户端相机、文字共用。 |
| DirectionalSkyCoverage | 每个调用方独立持有方向、覆盖与平滑状态；sample接收观察者、波头及最近波带位置，update按游戏刻双向平滑。清道夫保留自己的触发与距离配置。 |

退出世界时统一清空公共交互和相机注册。正常结束与跳过分别解除本来源控制，不会清掉其他功能的限制。清道夫跳过包只释放发送玩家与匹配事件的服务端开幕锁，持续天空和CRT不随跳过关闭。网络协议为32，双端必须配套。

主分支同类操作已接入：指挥家独立机位、移动屏蔽，清道夫相机、FOV、输入、字幕时间轴与天空覆盖。业务参数保留在所属功能；没有改写女皇、激光或Photon播放器。Java编译与IDE检查不能替代游戏、光影或视觉验收。
