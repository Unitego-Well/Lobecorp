# WARP迁跃锚

物品ID：普通版`lobecorp:warp_anchor`、后巷深宵版`lobecorp:warp_anchor_backstreets_midnight`；耗材：`lobecorp:canned_enkephalin`（罐装脑啡肽）。两者加入脑叶公司创造模式物品栏，未添加合成配方。

- 未记录时按住右键5秒，保存当前使用者的精确坐标、维度、水平和垂直视角；记录保存在该物品上，随存档持久化。
- 有返记录时，右键蓄力5秒优先返回该点，成功后清除返记录，不保存本次出发位置。没有返记录而有固定锚点时，传送至固定锚点，成功后将出发前坐标、维度和视角保存为一次性返记录。
- 传送包含使用者和以其当前脚下位置为底面中心、边长11格立方体内的实体，使用者抵达所选记录点，同行实体按出发时相对使用者的三维偏移平移。范围按实体位置判断，包含其他玩家和掉落物；使用者恢复记录视角，其余实体保留自身视角。
- Shift＋右键蓄力5秒先清除返记录；没有返记录时才清除固定锚点。每次仅清一种记录、消耗一罐。操作类型在开始蓄力时确定；提前松开不执行。
- anchor_editable默认true；false时禁止新建或清除固定锚点，但仍可传送、生成返记录、返回后清除返记录，或手动清除返记录。被锁定的操作不扣耗材。
- 记录、传送、清除各消耗1罐脑啡肽，创造模式也消耗。耗材从玩家物品栏查找；不足、无记录可清除或目的维度不存在时不扣除。
- 骑乘关系在传送前解除，避免递归携带范围外乘客。传送遵循原版实体接口，目标方块空间不自动清理，不添加专属维度。

描述：「目的地已经确定。同行者的意愿不在受理范围内。」

脑啡肽模型及饮用动画已从ImaginaryCraft移植：背包显示原GUI贴图，手持和掉落使用原三维罐体；右键饮用84刻（4.2秒），完成消耗一罐，不增加治疗或饱食度。动作包含开罐、饮用、收手和约4秒处罐体隐藏，左右手按玩家主手设置镜像，第一及第三人称共用现有玩家动画系统，中途停止使用会结束播放。开罐、两种饮用、饮尽音频保留原始文件及音量/音调参数，打嗝复用原版声音。参考项目的抛罐粒子回调原本已禁用，本次不启用。迁跃锚的扣除不播放饮用动画，两种迁跃锚使用用户提供的16×16纹理assets/lobecorp/textures/item/warp_anchor.png。

## 独立数据组件与往返（2026-11-11）

组件ID为`lobecorp:warp_anchor`，由`registry/world/item/LcDataComponents`登记，数据类型为`world/item/component/WarpAnchor`。通过Codec持久化、StreamCodec随物品同步；新物品自带空组件。全部迁跃状态仅存于该组件，不再读写通用CUSTOM_DATA，不读取或迁移旧记录。

| 字段 | 内容 |
|---|---|
| anchor | 可选目标：dimension和可选location；location含position、yaw、pitch，缺省表示地表模式 |
| return_point | 一次性返记录，捕获时总是保存固定location |
| anchor_editable | 默认true；只控制固定锚点是否允许记录或清除 |
| clearing | 默认false；本次蓄力是否为清除，开始使用时确定，正常松开或结算时复位 |

组件使用不可变record，所有更新均替换物品上的组件值；不维护玩家UUID绑定、额外Map或独立文件。修改权限可由代码的withAnchorEditable或标准物品组件命令/数据操作设置，未新增切换权限的玩家交互。

例：固定锚点为A，玩家在B使用则前往A并保存B；再次使用返回B且删除返记录；之后再次使用重新前往A并保存新的出发点。固定锚点A不被往返流程覆盖。目的维度不存在或使用者传送失败时不修改返记录、不扣耗材；使用者成功后再转移同行实体，同行实体仍受原版及其他模组传送限制。

验证：组件注册和新增翻译的compileJava/runData通过（49秒），最新一次性返回逻辑的compileJava/processResources通过（8秒），六份Java的IDEA错误检查通过。未进游戏验证往返、联机同步、存档读写或锁定交互。

## 后巷深宵预设与地表目标（2026-11-11）

`registry/world/item/LcItems.WARP_ANCHOR_BACKSTREETS_MIDNIGHT`直接声明为DeferredItem<WarpAnchorItem>，物品ID为lobecorp:warp_anchor_backstreets_midnight。名称「WARP迁跃锚-后巷深宵」随注册声明登记，默认组件保存锁定的地表目标。普通版和专用版都由创造栏的LcItems.REGISTER列表自动收录，原堆栈预设工厂已删除。两者共用生成模型lobecorp:item/warp_anchor和用户提供的16×16纹理，纹理不做修改。

预设anchor只保存深夜清扫维度键，不保存location，并设置anchor_editable=false。固定位置模式保存完整location；返记录总是固定位置，不受地表解析影响。组件结构按本次要求直接扩展，不增加旧记录迁移。

地表模式保留出发时精确X/Z和视角，加载目标区块后查询MOTION_BLOCKING_NO_LEAVES高度图，以其高度作为脚部Y，不写死超平坦高度。目标列须在边界内、脚下无液体且具有完整向上支撑面；使用者及范围内同行实体的目标包围盒须满足高度、边界、方块/流体/现存实体碰撞检查。不能通过时不传送、不更新返记录、不扣耗材；不挖方块、搭平台或随机寻找其他坐标。普通固定点及返回固定点同样保留同行实体相对偏移。

锁定预设不能记录新目标或清除目标，但进入后仍保存一次性返记录；再次使用优先返回并在成功后清除返记录。Shift也可先行清除返记录。蓄力5秒、11格边长立方体和每次一罐消耗不变。

## 蓄力粒子与移动取消（2026-11-12）

实际传送（包括返回）蓄力时，淡蓝色11×11空心水平框从玩家当前脚下Y+11下降至脚下Y，持续5秒。传送范围与粒子均按玩家当前脚下位置作为底面中心，X/Z各±5.5，Y为当前脚下至其上11格，不再向脚下延伸。记录及清除操作不绘制传送框。

charge_origin保存在迁跃锚组件内，记录实际传送蓄力开始时的维度与位置，仅用于移动检查，不作为范围或显示中心。服务端每次使用tick及结算前检查位置，距离平方超过1e-6（位移约0.001格）或维度变化即取消，停止使用并清理蓄力状态，不扣耗材、不修改目的地或返记录；单纯转动视角不取消。正常松开及结算也清理charge_origin。

客户端复用原生Dust粒子，四边每半格一点，每帧88个点；复用既有ClientTick唯一入口，上一帧粒子主动移除，停止使用或移动后停止绘制，不新增粒子注册、资源或网络包。客户端统一LIGHT_BLUE=0x9BDFFF，同时用于NEW理智条高理智数值文本，低理智与其余文本颜色保持原值。

未进游戏进行粒子、移动取消、HUD或视觉验收。

## 相对位置传送（2026-11-12）

使用者作为基准抵达所选目标点；同行实体目标=使用者目标+（实体出发位置−使用者出发位置）。前往固定锚点、地表目标及一次性返回均采用此规则。三维偏移按世界坐标直接平移，不随玩家视角旋转；使用者恢复目标视角，同行实体保留各自朝向。

目标坐标与朝向在解除骑乘和玩家传送之前冻结，防止下马或跨维度改变参照。地表安全检查使用每个同行实体偏移后的实际落点及包围盒。范围、五秒蓄力、移动取消和一罐消耗不变。

未进游戏验收队形、跨维度或往返。
