# 任务提示词与接续

范围：Lobecorp 项目专项；来源：原工作流程对应章节；维护：2026-11-10。通用授权与执行遵守[项目入口](../../../AGENTS.md)所指共享协议，本文不产生新授权。

## 提示词与执行效率（所有会话适用）

适用于主会话、GPT/DS子会话、任务派发、续接、纠偏和交接等所有提示词，不限模型。减少Token与耗时依靠消除重复，不以省略必要上下文、降低质量或提前结束换取。

- 提示词先给目标、当前阶段和完成标准，再给必要事实、真实目录/写域、工具与权限、验证和交付；同一事实只写一次。短任务直接明确要求，不套长流程；复杂任务按实际依赖组织，不堆无关历史、完整日志、重复规则或空洞强调。
- 只写本次适用约束，通用制度维护唯一正文；涉及当前任务的关键边界仍显式写清。续接保留当前状态、已批准决策、差异与剩余工作，删除已结束过程的重复叙述；DS等要求自足任务包时不能用“同上”代替必填内容。
- 读取先定位入口、相关章节和符号，确有缺口再扩大范围；复用已读且未变化的内容。修改前核实当前Document/WIP与易变事实，不默认通读历史或全仓扫描。
- 独立查询合批并行，依赖步骤和写操作顺序执行；每项检查错误和截断。工具发现仅查所需名称及schema，输出限相关范围，完整证据留文件，用摘要与路径回报。
- 简单任务直接由主线处理；委派应有实质收益，按可独立交付的模块/阶段划分，不拆成大量零碎任务。模型专属选择、复用和轮换遵守对应规则，不为并行制造重复研究或写入冲突。
- 优先主动回报和有界等待，使用游标读取增量，不高频轮询或重复输出无变化状态；必要进度节奏仍遵守。提示词发送成功不等于任务完成，负责人持续审核推进。
- 全部代码完成后统一检查和已授权验证；条件未变的有效证据复用，不重复构建或重新执行已完成步骤。默认验证范围按验证章节，不为提速越过授权。
- 输出以结论、关键证据、实际限制和必要下一步为主，不复述整份提示词或工具流水账。任务完成且证据充分即收尾，不追加无关检查。
