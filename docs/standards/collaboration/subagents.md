# 项目子代理与 DS 路由

范围：Lobecorp 项目专项；来源：原工作流程对应章节；维护：2026-11-10。通用授权与执行遵守[项目入口](../../../AGENTS.md)所指共享协议，本文不产生新授权。

## 子代理模型与渠道

- 项目子代理统一使用 GPT-6.1 Terra；创建、接续、重新委派及模型变更时均按本节选择模型与渠道。用户对当前任务明确指定其他模型时，以用户指令为准。
- 根据主会话实际调用渠道选择对应的 GPT-6.1 Terra：主会话使用官方渠道时，子代理使用官方渠道；主会话使用中转渠道时，子代理使用中转渠道；无法确定主会话渠道时，默认使用官方渠道。
- 调用前依据可核实的主会话模型、提供方信息及当前可用模型目录核对渠道和实际模型 ID，不凭模型名称猜测渠道，不硬编码可能变化的中转 ID。目标模型或渠道不可用时如实说明，不自行替换为其他模型或渠道。
- 本节仅约束子代理模型与渠道，不改变主会话配置；DS 专项调用仍按下文对应规则执行。

## 子代理最低推理档位

- 项目内所有子代理只能使用所选模型或代理接口支持的最低推理档位，创建、接续、重新委派及模型变更时均须显式指定；不得因任务复杂、审查或集成需要自行提高。
- 按当前接口实际能力选择最低档，例如支持 none 则使用 none，仅支持 low 起步则使用 low；不把不受支持的档位当成已生效。接口无法设置时如实说明，不声称已指定最低档。
- 本规则仅约束子代理，不修改主对话的推理档位或模型；用户对当前任务的明确指令优先。


## DS 简单任务委派与停止检查

通用职责、当前中转型号、调用入口与上下文轮换统一见[DS协作规则版本化快照](ds-collaboration.md)。项目交接位置与索引遵守[代理文档管理](../documentation/agent-docs.md)，本项目既有轮换与回报授权仅在其原范围有效，不因迁移扩大业务或解除停工。
