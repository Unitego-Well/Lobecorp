# 实体动画与模型 LOD

仅调整客户端显式接入的实体视觉工作量，不改变技能、伤害、碰撞或服务端时间；Photon 特效部分另行维护。

- 配置入口：模组列表 → Lobecorp → 配置，文件 `lobecorp-visual-quality.toml`。
- 女皇与清道夫的五个控制器通过 `LcAnimationControllerUtil.withDistanceLod` 接入：默认 50 格外 30 FPS、80 格外 12 FPS；关键帧事件与控制器时间继续推进。
- 姿态缓存只保存本层贡献，首次呈现、触发版本、动画/骨骼身份、循环和时间回退会重新采样；保留首次默认姿态免淡入规则。
- 两种实体模型经 `LcModelLodUtil.capture` 显式接入；至少 64 个立方体才省略细节，默认 50/100 格两档，细节尺寸 0.5/2 模型单位。骨架、定位器、主体与无法可靠区分主体的部件保留。
- 每种缓存默认 256 项/32 MiB，每帧最多准备 2 个模型；资源预算不足临时绘制原模型，退出与世界卸载清理。可按实体/控制器名单及 `LcModelLodUtil.setExempt` 豁免。
- 距离档位由通用 `LcVisualQualityUtil.band` 提供，实体侧不依赖 Photon 的质量工具。

此提交只包含上述实体侧设置。与特效共用文件中的 Photon 参数、编辑器设置和渲染实现继续保留在本地待重写。

当前工作区三份相关 Java 的 IDEA 编译通过、Data exitCode=0；保留既有 Mixin/Level 等警告。提交拆分版本尚未在独立检出中构建，远距离视觉与性能未在本轮游戏验收，不据此承诺帧率。
