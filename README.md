# Lobecorp Photon 工作区

本工作区负责 Photon 编辑器、模型特效、命名播放、子特效、女皇光束表现及 G1 资源验收。当前分支为 `codex/photon`，真实目录为 `E:/xm/mc/mod/Unitego-Well/Lobecorp/.workspace/lobecorp_photon`。

从 [文档总索引](docs/README.md) 与 [Photon 当前能力及恢复入口](docs/systems/photon-workspace.md) 开始，再按任务读取 [系统索引](docs/systems/README.md)。[Photon 唯一问题汇总](docs/issues.md) 区分当前实现、历史说明和缺失证据；[项目规则](AGENTS.md) 与共同基础文档继续有效。

Minecraft MCP 只使用本工作区 `lib` 制品，端口 `19877`；Normify 复用原始仓库 CLI，目标根和 cwd 限定本工作区。接入见 [Minecraft MCP 工作区说明](docs/systems/minecraft-mcp-workspace.md)。

业务进度、验收边界和未完成工作见 [工作区总览](docs/systems/photon-workspace.md)；开发约束以项目规则和用户当前授权为准。
