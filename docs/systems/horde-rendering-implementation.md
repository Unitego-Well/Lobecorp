# 深夜清扫：固定线路 GPU 三维浪潮

实现记录日期：2026-10-22；导航核对日期：2026-10-23。当前工作区为 `.workspace/lobecorp_horde`、分支 `codex/horde`，入口见 [Horde 索引](horde-index.md)。历史恢复工作区名为 horde-recovery；恢复快照为 `6328b11`，BenchMod 接入提交为 `1f30bde`。本文描述本次已写入的实现，构建、运行、视觉和性能状态分别记录，不能以旧版采样代替本版验收。

## 数据与职责

- 服务端保留事件、固定线路、真实参战分配和区域同步。虚拟单位不创建 Entity，不参与命中、AI 或实体生成判断。
- 移除密度和种子，默认纵横间距各 1 格；列数按宽度和横向间距计算，居中排列。稳定编号来自事件、行、列，不使用随机噪声。
- 事件开始时准备全部节点的横向五列高度，覆盖路线宽度及最大让行偏移；缺少必需区块即拒绝启动，不强加载，不以假高度补齐。运行期间不再修订地形。
- 客户端必须接收全部节点后才显示；生成弧长查找表、平滑方向和保守空间块。GPU 在查找表基础上定位原始路段，插值位置和横向高度。
- CPU 按空间块和统一时间反算活动行号，只提交行列区间；GPU 求单位位置、区域让行、朝向和动画。每批最多 65536 实例是绘制分块容量，不是总上限。
- 默认 maximumVisible=-1、rangeChunks=-1；已有配置值不被默认值覆盖。有上限时只按块距离和稳定顺序分配预算，不进行逐单位候选堆或排序。
- 新存档标识为 `lobecorp:horde_events_gpu_v1`，事件 format=1；不读取或转换旧活动事件，不删除旧存档文件。命令移除 seed 参数。

## 战斗区域与平滑让行

CPU 只处理区域级中心、大小和目标过渡数据，不计算逐单位让行。区域按稳定 ID 排序；每个空间块只关联可能影响其包围范围的区域。区域目标未变化时不提升版本，不重建或上传区域纹理。

GPU 根据旧值、目标值、统一时间和 transitionTicks 求区域状态；出现时由零扩张，消失时缩至零，结束后允许回收区域。过渡中再次更新先以区域当前插值参数作为新起点，不产生单位位置读回。

单位按原始出生列固定选择左右侧，中间列按列号奇偶决定；横向累计偏移不超过 regionMargin。让行后重新采样地面高度，并用相邻时间的最终位置计算朝向。

这是横向让行，不是路径搜索或碰撞求解。任意重叠区域不保证无穿插。地形变化也不会重新修订固定高度。

## 模型和动画

HordeMeshCache 从现有模型及 run 循环提取静态几何、骨骼归属和父链，以每秒 20 样本烘焙局部平移、旋转、缩放。GPU 对相邻样本执行最短路径四元数插值，并沿父链依次变换顶点及法线，保留层级缩放效果。

模型和动画数据共享，不创建逐个动画控制器，不写共享 GeoBone 状态，不执行动画事件。相位由行列公式决定。数据纹理使用 RGBA8 保存 float 的原始位模式，整数纹素读取后解码，不把数据当图片做线性过滤。

资源准备失败记录事件 ID 和异常，停止该事件虚拟显示；没有旧渲染回退。资源代际变化允许重新准备。骨骼父链最多 64 层，超限明确拒绝。

## 位置正确的原版光照

本版替代原计划的整块共享亮度：

1. CPU 按可见块收集已加载的 16×16×16 光照区段。
2. 读取原版 LevelLightEngine 的 BLOCK/SKY 压缩区段数据，每 5 tick 比较一次，仅上传变化区段。缺少天空光 DataLayer 时按原版竖列回退采样，不能当作零。
3. GPU 在让行后的最终单位位置，加上事件定义中实体尺寸的 eyeHeight，取对应方块及区段。
4. GPU 通过区段索引取两层 0—15 亮度，按原版 sample_lightmap 规则读取当前 lightmap。
5. 使用原版实体方向光照和变形后的法线，合成原贴图及 glowmask，再应用雾。

依据：EntityRenderer.getPackedLightCoords 使用 Entity.getLightProbePosition，默认是 getEyePosition；普通非燃烧实体的 block/sky 取值来自对应 LightLayer。虚拟单位没有燃烧实体状态，不额外强制满亮。

区段只按区域共享数据，不按单位上传或读回位置。光照更新最多有 5 tick 延迟；不在当前已加载区段索引中的单位不显示，不沿用卸载前亮度，也不伪造天空满亮。没有复制动态手持光源、光影包专用材质或阴影能力。

## 绘制与生命周期

只保留单一三维裁切表示，写深度，不做整模透明淡入、双表示渐变、LOD、CPU 光栅图集或 CPU 射线遮挡。CPU 保守执行区块、距离及空间块视锥判断，墙后像素由深度测试处理。

绘制仍位于世界颜色完成后、手部之前，跳过 Iris 阴影 pass，按 API 报告选择普通或反向深度。使用原版光照并不等于进入光影包 GBuffer；完整光影外观及后处理仍需实际验证，不承诺任意包兼容。

所有纹理准备、缓冲上传及索引扩容在 RenderPass 前完成。无计算着色器、原生 OpenGL 旁路或同步读回。事件结束释放线路和区域 GPU 数据；世界退出和资源重载释放共享模型、动画、光场和参数缓冲。TextureManager 持有的原始贴图只借用。

脚步声和扬尘消费可见空间块中心摘要，不依赖逐单位显示列表。少量聚合声源仍保留原有低频声音遮挡检测，不参与主体可见性。
